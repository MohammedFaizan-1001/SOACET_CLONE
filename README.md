# SOACET-CLONE

## About

SOACET-CLONE is a frontend project created to practice and improve my web development skills.

The project is inspired by the SOACET website and focuses on recreating its layout, design, navigation, banner, content sections, and footer using frontend technologies.

## Technologies

- HTML
- CSS
- JavaScript

## Features

- Responsive design
- Navigation bar
- Website logo
- Banner section
- Content sections
- Buttons and icons
- Footer
- Mobile-friendly layout
