# SOACET Website - Frontend Project

A frontend website project created to recreate and practice the design and layout of the SOACET website using HTML, CSS, and JavaScript.

## 🚀 Project Overview

This project focuses on building a clean and responsive website interface with a structured header, navigation menu, banner section, content sections, and footer.

The project was created as a frontend development practice project to improve skills in website structure, styling, layout, responsiveness, and basic JavaScript interactions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## ✨ Features

- Responsive website layout
- Website header and navigation
- SOACET logo section
- Banner section
- Styled navigation links
- Content sections
- Footer section
- JavaScript interactions
- Responsive design for different screen sizes
